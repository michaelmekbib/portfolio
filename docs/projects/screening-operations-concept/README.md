# Ebola Response Screening Operations Concept

A proposed “one passenger, one record” approach to port-health screening operations.

**Status:** Concept and recommendation under review  
**Contribution:** Michael Sileshi Mekbib  
**Repository contents:** Project case study. This directory contains documentation; institutional application source is not included.

## Problem

Separate passenger lists, spreadsheets, and response systems required manual reconciliation and repeated data entry.

## My contribution

Documented workflow observations during the 2026 Washington Dulles response deployment and authored the proposed current-to-future workflow, enterprise capability, and implementation considerations.

## Results and scope

Produced a concept for manifest import, coordinated worklists, assessments, exception review, reporting, and staffing. Faster screening and reduced duplicate entry are expected benefits, not measured deployment outcomes.

## Tools and methods

Workflow mapping, informatics analysis, response operations; proposed integration with 1CDP and QARS.
