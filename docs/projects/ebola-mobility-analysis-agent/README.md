# Ebola Population Mobility Analysis Agent

I developed a Microsoft Copilot-based agent to support population mobility analysis for Ebola response planning.

**Platform:** Microsoft Copilot  
**Focus:** Population mobility, evidence synthesis, response planning  
**Access:** Internal CDC

## The challenge

Population mobility analysis draws on international reports, maps, and assessments. Bringing this information together helps response teams understand movement patterns and relevant cross-border context.

## My contribution

I led the mobility analysis and developed an AI-assisted workflow to synthesize these materials into insights for response planning. The Copilot agent supports that analysis by helping organize and explore the information.
