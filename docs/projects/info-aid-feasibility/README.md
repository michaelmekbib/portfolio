# Info Aid Feasibility Assessment

**An assessment of SharePoint and Microsoft Power Platform for modernizing continuing education accreditation workflows.**

**Status:** Feasibility assessment completed; implementation depends on enterprise decisions  
**My role:** Feasibility analysis, requirements interpretation, workflow assessment, and modernization recommendations  
**Platforms assessed:** SharePoint, Dataverse, Power Apps, Power Automate, and related Microsoft 365 capabilities

## The question

A prior recommendation favored SharePoint and Power Platform. The Info-Aid assessed whether that approach could support the accreditation process before further investment, using a Government Accountability Office-informed assessment approach.

## Assessment findings

The presentation found a credible technical fit while distinguishing capability from implementation readiness. Its final findings describe:

| Dimension | Assessment rating | Conditions or interpretation |
| --- | --- | --- |
| Technical | High | Platform capabilities fit the proposed data and workflow model. |
| Governance | Conditional | Tenant policy, identity governance, and external-access decisions require confirmation. |
| Operational | Conditional | Ownership, development capacity, environments, and support arrangements must be established. |
| Scalability | High | The assessment anticipates support for larger workloads and collaborator groups with appropriate roles. |
| User adoption | High | Training and support remain necessary for collaboration and review. |

These are ratings from the project assessment, not independent certifications or evidence of production performance. Resource and licensing questions remain implementation dependencies.

## Modernization opportunities

The proposed future state connects digital intake, parallel approvals, status tracking, document reuse, version control, and audit records. A shared activity record would reduce repeated entry across forms, while workflow notifications and reporting would make outstanding work easier to track.

These are proposed workflow changes. Faster intake, shorter approval cycles, and reduced duplicate entry have not been demonstrated as measured implementation outcomes in the supplied deck.

## Recommendations before development

Confirm the tenant and connector environment, external-access approach, internal technical capacity, licensing implications, and workflow crosswalk before building the flows. Establish a support and stewardship model for the resulting service.
