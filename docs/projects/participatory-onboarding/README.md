# Informatics Driven Participatory Onboarding

A participatory onboarding model, relational dashboard, and information assistant.

**Status:** Implemented knowledge system; continuing asset  
**Contribution:** Michael Sileshi Mekbib  
**Repository contents:** Project case study. This directory contains documentation; institutional application source is not included.

## Problem

Orientation materials did not adequately surface site-specific roles, project dependencies, data workflows, and collaboration networks.

## My contribution

Conceived the Initialize–Discover–Assess–Blend model; conducted interviews and document review; built the dashboard, knowledge structure, and assistant use cases.

## Results and scope

Reached 81% participation and mapped 30+ projects, with active work within two months. The information assistant extends access to roles, subject-matter experts, and project connections.

## Tools and methods

Power BI, SharePoint, interviews, document review, stakeholder mapping, conversational AI.
