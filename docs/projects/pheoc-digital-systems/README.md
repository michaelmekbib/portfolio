# PHEOC Digital Systems

Digitization, data-management training, and dashboard examples for public health emergency operations centers.

**Status:** Project leadership and implementation support  
**Contribution:** Michael Sileshi Mekbib  
**Repository contents:** Project case study. This directory contains documentation; institutional application source is not included.

## Problem

Emergency operations require connected information systems, reliable reporting, and staff capacity to use data during response.

## My contribution

Led PHEOC digitization and data-management training across 23+ African Union member states. Supported continental emergency preparedness and outbreak-monitoring initiatives.

## Results and scope

Contributed to a wider PHEOC strengthening initiative supporting 31 member states. The 31-state initiative scope is distinct from the 23+ states described for direct digitization and training work.

## Tools and methods

Public health information systems, Power BI, project management, data-management training, outbreak monitoring.
