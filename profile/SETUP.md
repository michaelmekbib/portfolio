# Activate the GitHub profile hub

The profile README is prepared in [README.md](README.md). Its header image is hosted in the portfolio repository, so only the README needs copying to the profile repository.

## Create the special profile repository

Create a public repository named exactly `michaelmekbib` under `michaelmekbib`. Initialize it with a README, then replace the README with the content from this directory’s README.

[Create the profile repository](https://github.com/new?owner=michaelmekbib&name=michaelmekbib&visibility=public&auto_init=true&description=Public+health+informatics+and+digital+health+portfolio)

The existing `michael-mekbib` repository is a React application. Keep it separate; its name does not activate the profile README.
